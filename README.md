# salary prediction

## project description
-This project predicts employee salaries using Machine Learning.
## Technologies used
-Python
-Pandas
-NumPy
-Linear regression
## Dataset 
The data set contains:
-Experience
-Test score 
-Salary
## Machine Learning Model
-Multiple Linear Regression is used to predict salary based on experience and test score.
## Evaluation
The model is evaluated using: 
-Mean Squared Error (MSE)
-R² Score
